# PromoBar

Franja `brand-black` de una línea encima de la navegación, editable desde el panel de administración (tabla `promo_bar`).

## Uso
- Un solo mensaje, máximo unos 90 caracteres. Resalta la parte clave con `<b>` en `brand-leaf` (6.5:1 sobre negro).
- Puede llevar un enlace («Ver ofertas»), subrayado.
- En móvil el texto pasa a dos líneas; no lo animes como carrusel.
