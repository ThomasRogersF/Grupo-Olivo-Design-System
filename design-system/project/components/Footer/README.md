# Footer

Pie en cuatro columnas sobre `surface`, separado por un filete `rule`.

## Uso
- Columna 1: logo a color (22px), una línea de quiénes somos y la afiliación a la Cámara Venezolana del Libro.
- Columnas: Libros, Autores (servicios y concursos), Contacto.
- Correo y teléfono como texto seleccionable además de enlace.
- En móvil: dos columnas; la primera ocupa todo el ancho.
