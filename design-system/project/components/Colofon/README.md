# Colofon

La ficha técnica del libro escrita como el colofón de un libro impreso: etiqueta en mono `accent`, valor en sans.

## Uso
- En la página del libro y en la sección destacada del inicio.
- Campos en este orden cuando existan: Título, Autor/a, Sello, Colección, ISBN, Páginas, Formato, Precio.
- Omite los campos sin dato en vez de poner «—». El ISBN de la vista previa viene del enlace de Amazon de Fleur.
