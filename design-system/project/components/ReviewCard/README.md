# ReviewCard

Una reseña: inicial, nombre, fecha, estrellas, texto en serif y la marca «Compra verificada» si aplica.

## Uso
- Texto en Libre Caslon Text a 17px, máximo 640px de ancho.
- Separador `rule` arriba; las reseñas se apilan sin tarjetas.
- «Compra verificada» solo si el usuario tiene un pedido aprobado de ese libro.
- El contenido de la vista previa es de muestra: no hay reseñas reales todavía.
