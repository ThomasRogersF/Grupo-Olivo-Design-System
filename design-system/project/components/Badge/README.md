# Badge

Etiqueta corta en mono con un punto de color: comunica estado con palabra y color a la vez.

## Variantes
- `--new`: libros nuevos, sobre la portada en BookCard. Fondo `ink`, punto `brand-leaf`.
- `--warning`: «Pendiente de verificación» (pagos manuales aún sin aprobar).
- `--success`: «Pago aprobado».
- `--danger`: «Pago rechazado».
- `--neutral`: estados informativos como «Enviado» o «Agotado».

## Accesibilidad
El estado siempre se lee en el texto. El verde y el rojo se distinguen por la palabra, no solo por el tono.
