# Eyebrow

Rótulo corto en IBM Plex Mono que anuncia una sección, un sello o un dato de colofón.

## Uso
- Úsalo encima de cada titular `display-l` o `display-xl`, nunca solo.
- Texto en `accent`, estilo `label` (11px, mayúsculas, +0.08em). Escribe el texto en minúsculas normales: el CSS lo pasa a mayúsculas.
- `go-eyebrow--bare` quita el filete de 28px; úsalo dentro de tarjetas y filas estrechas.

## Lo que provee quien lo usa
Un texto de 2 a 5 palabras. Para separar dos datos usa ` · `.

## No
- No lo uses como botón o enlace.
- No más de un eyebrow por bloque.
