# SelloFilter

Tabs en píldora para filtrar el catálogo; la activa se rellena de `ink`.

## Uso
- Un solo filtro activo (`aria-pressed="true"`). El conteo es opcional.
- Al cambiar, el catálogo se reordena con GSAP Flip: las tarjetas que salen se encogen a 0.92 y se desvanecen, y las que quedan se deslizan a su lugar.
- Sellos: tucoach.go, Alita, Reto Escritor e Independientes (Hechos Criollos está por confirmar).
