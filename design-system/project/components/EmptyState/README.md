# EmptyState

Mensaje centrado para listas sin contenido, con las dos «O» del logo como motivo.

## Uso
- Título en display que diga qué pasa («Tu carrito está vacío», «No hay libros en este sello todavía»), una frase que diga qué hacer y una acción.
- Los círculos usan `brand-green` y `brand-leaf`: son un motivo derivado del logo, no el logo. Nunca los acompañes de las letras.
