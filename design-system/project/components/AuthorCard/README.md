# AuthorCard

Foto circular, sello, nombre en display y una biografía de dos o tres líneas.

## Uso
- Foto cuadrada recortada a círculo de 96px (64px en móvil). Si no hay foto, usa la inicial sobre `accent-soft`.
- Biografía de `AUTORES_.docx`, recortada a unas 40 palabras; la completa va en la página de autor.
- Enlaces: «Ver sus libros» y su Instagram si existe.
